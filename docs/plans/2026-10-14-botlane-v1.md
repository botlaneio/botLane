# BotLane.io v1 Implementation Plan

> To execute: use the executing-plans skill, task by task. Steps use `- [ ]` checkboxes.

**Goal:** Replace the current self-serve site with the approved "managed AI workflows" design: every page from the sitemap below, built in this repo and deployable on the existing Cloudflare Worker.

**Architecture:** Next.js App Router with static server components for every marketing page. Client components only where interaction needs them: the header, mobile menu, mobile action bar, scroll hero, FAQ, forms and scheduler. All copy lives in typed content files under `src/content/`, so copy changes never touch layout code. The forms are server actions that post to a webhook configured by env vars (the same Apps Script pattern the site already uses).

**Tech stack:** Next.js 16.3.8 (pinned, see README), React 19, TypeScript strict, Tailwind CSS 4, shadcn/ui-style primitives (cva + Radix Accordion/Dialog/Slot), GSAP 3 + ScrollTrigger (hero only), zod, Vitest. Deploy: OpenNext on Cloudflare Workers (unchanged).

**Spec:** `/mnt/project-files/botlane/2026-10-14-botlane-design-plan.md` (Revisions 2 to 2.3 override earlier sections), approved preview https://claude.ai/artifact/VWDXeAwjwWaZsSzKRkVyQ8 (v9), and the 4-frame mockup `specs/mockup-4-pages.png` (Home, Solutions, How it works, About).

## Global constraints
- Fonts: Newsreader 400 (+ italic) for H1/H2 and pull quotes; Geist for everything else. One italic phrase per hero headline, coloured `--terra`.
- Tokens: ink `#17191c`, white, fog `#fafafb`, mist `#f2f2f3`, line `#e9e9ec`, muted `#5f636d`, subtle `#6b6f7a`, peach `#fbe1d1`, sienna `#5d2a1a`, terra `#9a5232`, ok `#1f6b45`, ok-tint `#e4f0e8`, danger `#b3261e`. Components never use raw hex.
- Every button has an 8px radius (`--r-btn: 8px`); minimum height is 44px, except the 36px header button.
- Gutters `clamp(24px, 5vw, 80px)`, content max-width 1280px. Nav-to-hero gap `clamp(120px, 19vh, 190px)` on the home hero.
- Peach as a surface appears at most once per page. Green is used only for "Approved"/"Sent".
- Copy: never fabricate testimonials, customer results, prices, guarantees, certifications or timelines. Illustrative numbers carry an "Example" label. No "50+" integrations claim.
- WhatsApp number, contact email and booking link come from env vars. When a var is unset, its button is hidden; no placeholder number is ever shown.
- WCAG 2.2 AA: visible focus ring, 44px targets, one H1 per page, labelled inputs, `prefers-reduced-motion` turns off all motion.
- Scroll hero animates only at ≥1024px with motion allowed. Everywhere else it shows the assembled window statically.

## Review focus
1. **Narrow phones (360px):** long serif headlines and the five-card solutions grid must not overflow. Test: the smoke script fails if any page's HTML contains a fixed width above 400px outside `.stage` (Task 3), plus a manual check at 360px.
2. **Missing env vars at launch:** with no WhatsApp/email/calendar configured, nothing broken or fake renders. Test: `contact.test.ts` asserts that `whatsappHref()` returns `null` when the env var is unset (Task 2).
3. **Webhook down or unset:** the assessment form keeps the visitor's data and shows another way to reach us. Test: `inquiry.test.ts`, where a fetch failure returns `{status:"error"}` with no thrown error (Task 7).
4. **Spam/bots:** honeypot and too-fast submissions are silently accepted and not delivered. Test in `inquiry.test.ts` (Task 7).
5. **Old links:** each redirect returns 308 to the right path. Test: smoke script (Task 8).

## File structure
```
src/app/layout.tsx                 fonts, metadata base, skip link, header/footer shell
src/app/globals.css                tokens, @theme mapping, base, .wrap, .btn, reveals
src/app/(site)/...                 marketing pages (share SiteHeader + SiteFooter + MobileActionBar)
src/app/(focus)/book, assessment   conversion pages (focused header, no action bar)
src/app/not-found.tsx, sitemap.ts, robots.ts
src/components/ui/                 button.tsx, accordion.tsx, sheet.tsx (shadcn pattern)
src/components/site/               site-header, mobile-menu, site-footer, mobile-action-bar, cta-pair, whatsapp-button, closing-cta, section-header, reveal
src/components/hero/               home-hero.tsx (markup), hero-stage.tsx (client, GSAP), hero.css
src/components/illustrations/      small card illustrations reused on solutions/how/about
src/components/forms/              assessment-form.tsx, scheduler.tsx
src/content/                       site.ts (nav, contact), solutions.ts, steps.ts, faq.ts, safeguards.ts
src/lib/                           contact.ts, inquiry.ts (zod schema + delivery), utils.ts (cn)
scripts/smoke.mjs                  starts nothing; fetches a running server and checks routes/redirects
```
Old pages and components (assemble/, auth/, home/, pricing.tsx, partners, signin, signup, etc.) are deleted.
